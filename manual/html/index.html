annunciator User Manual¶

Document number:

ANN-UM-001

Issue:

3

Issue date:

2026-11-13

Applicable software:

annunciator, version 1.1.1

Author:

Tom Scott

annunciator is a Python library for error, warning and information handling and for logs. This manual tells you how to install the library, how to use it and how to correct problems.

If you are a new user, read Information for use of this manual first. Then do the procedure Record your first events.
