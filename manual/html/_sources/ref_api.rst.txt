Programming interface
=====================

This section gives the reference data for each public module. The text
comes from the documentation text in the source code.

You can import the primary names directly from the package
``annunciator``. For example, ``from annunciator import get_logger`` and
``from annunciator.logger import get_logger`` give the same function.
