10. Conformity to standards¶

This chapter tells you how the manual applies the two standards in Table 9.1. It also gives the limits of the conformity statement.

10.1. Structure and content: ISO/IEC/IEEE 26514:2022¶

Table 10.1 shows where the manual gives each information component that the standard defines for information for users.

The manual also applies these principles of the standard:

  • The procedures are task-oriented. Each procedure has a purpose, initial conditions, numbered steps and a result.

  • The reference data are separate from the procedures.

  • The same term always has the same meaning. Glossary defines the terms.

  • The message reference comes directly from the software. Thus the manual and the software agree.

10.2. Language: ASD-STE100 Issue 9¶

The text of the manual applies the writing rules of the specification. Table 10.2 gives the primary rules and their application.

Table 10.2 Application of the writing rules¶

Rule

Use approved words with their approved meanings.

Applied. Technical names and technical verbs are in Table 2.3 and Table 2.4.

The documentation text in the source code applies the same rules. That text is the source of Programming interface.

10.3. Limits of the conformity statement¶

Note

The author applied the two standards during the preparation of this manual. An independent organisation did not examine the manual.

These limits apply:

  • The tool ste_check.py examines sentence length, paragraph length, contractions and a list of words that are not approved. It does not contain the full dictionary of the specification.

  • The tool cannot examine the meaning of a word or the voice of a sentence. A person must examine these items.

  • Text that comes from other software is not in Simplified Technical English. Examples are Python tracebacks and the names in program code.

  • The licence text in the file LICENSE is a legal text. The writing rules do not apply to it.

If your organisation must show formal conformity, a qualified person must examine the manual against the two standards.
