2. Information for use of this manual¶

2.1. Purpose of the manual¶

This manual gives the instructions and the reference data for the annunciator library. It tells you how to do these tasks:

  • install the library,

  • record information, warnings and errors,

  • define messages that have a code, a cause and a remedy,

  • handle exceptions with a standard policy,

  • examine log files,

  • monitor long runs and compare runs,

  • show that a log file did not change,

  • find the cause of a message and correct the problem.

2.2. Audience¶

The manual is for two groups of users.

Developers

Persons who write Python programs that use the library. You must know how to write Python functions and classes. You must know how to use exceptions. Knowledge of the standard logging module helps, but it is not necessary.

Operators

Persons who run a program that uses the library and who read its messages and its log files. You must know how to use a terminal. Knowledge of Python is not necessary. Read Messages and problem resolution and Command-line interface.

2.3. Scope¶

The manual includes the full function of version 1.1.1 of the library. It does not give instructions for Python, for the standard logging module or for Sphinx. Related information tells you where to find those instructions.

2.5. Conventions¶

Table 2.2 Typographic conventions¶

Convention

Meaning

monospace text

Text that you type, text that the computer shows, and names in the program code.

UPPER_CASE in a command

A value that you must replace, for example FILE.

[text] in a command

An optional part of a command.

>>>

The prompt of the interactive Python interpreter. Do not type it.

$ or a line without prompt in a console block

A command for the terminal.

2.6. Critical information¶

The manual uses two types of critical information. The use of this software cannot cause injury to persons. Thus the manual contains no warnings.

Caution

A caution tells you that data loss, disclosure of secret data or an incorrect result is possible. Obey the instruction in the caution.

Note

A note gives you information that helps you to do a task.

A caution or a note that applies to a step comes immediately before that step.

2.7. Language¶

The text of this manual obeys the writing rules of ASD-STE100 Simplified Technical English, Issue 9. The spelling is British English.

The names in Table 2.3 are technical names in this manual. The verbs in Table 2.4 are technical verbs. Glossary gives the definitions of the technical names.
