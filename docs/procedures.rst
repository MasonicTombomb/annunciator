Procedures
==========

This chapter contains the procedures for the usual tasks. Do the procedure
:doc:`proc_quickstart` first. You can do the other procedures in any
sequence.

.. list-table:: Procedures
   :name: tab-procedures
   :widths: 40 60
   :header-rows: 1

   * - Task
     - Procedure
   * - Record your first events
     - :doc:`proc_quickstart`
   * - Select the destinations and the formats
     - :doc:`proc_configure`
   * - Record information, warnings and errors
     - :doc:`proc_log`
   * - Give a code, a cause and a remedy to each message
     - :doc:`proc_catalogue`
   * - Raise and catch errors that have a code
     - :doc:`proc_errors`
   * - Tell the user about a condition without an exception
     - :doc:`proc_warnings`
   * - Apply a standard policy to exceptions
     - :doc:`proc_handling`
   * - Record exceptions that no code caught
     - :doc:`proc_hooks`
   * - Examine and summarise a log
     - :doc:`proc_reports`
   * - Write the message reference of your own manual
     - :doc:`proc_sphinx`
   * - Get the necessary information from a run of many hours
     - :doc:`proc_longrun`
   * - Record a manifest, protect a log file and compare runs
     - :doc:`proc_runs`
   * - Use many processes, keep local variables and examine data
     - :doc:`proc_robust`
   * - Find incorrect codes, write tests and make an HTML report
     - :doc:`proc_devtools`
